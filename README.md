## Quick Start

1. Open `poster/poster.html` in Chrome/Edge
2. Press `Ctrl+P`
3. Set **Paper size** → **A0** (or A1 if your printer supports it)
4. Set **Margins** → **None**
5. Set **Scale** → **100%**
6. Print
