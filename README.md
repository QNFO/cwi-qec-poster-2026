## Quick Start (either poster)

1. Open the HTML in Chrome/Edge
2. Press `Ctrl+P`
3. Set **Paper size** → **A0** (or A1 if your printer supports it)
4. Set **Margins** → **None**, **Scale** → **100%**
5. Print
